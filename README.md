# Ismail Marble & Granite

Premium responsive React/Vite website for Ismail Marble & Granite, Lahore.

## Local development
```bash
npm install
npm run dev
```

## Build for Vercel
- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`

## GitHub
Extract this ZIP, then upload the **contents of the project folder** to your GitHub repository. Do not upload the ZIP itself, `node_modules`, or `dist`.
